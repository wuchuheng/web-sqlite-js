Basic Example

This is a minimal example showing basic CRUD operations with web-sqlite-js.

It demonstrates:

  • Opening a database
  • Creating tables
  • Inserting data with named parameters
  • Querying data with positional parameters

Code

import WebSqlite from "../dist/index.js";
const db = await WebSqlite("hello-word.sqlite", { debug: true });

// Create table
await db.exec("CREATE TABLE IF NOT EXISTS test (id INTEGER PRIMARY KEY, name TEXT);");

// Insert with named parameters
await db.exec("INSERT INTO test (id, name) VALUES ($id, $name);", {
  $id: 1,
  $name: "Alice",
});

// Query with positional parameters
const rows = await db.query("SELECT * FROM test WHERE id IN (?, ?) ORDER BY id;", [1, 2]);

Result

Check the browser console (F12) for results.
